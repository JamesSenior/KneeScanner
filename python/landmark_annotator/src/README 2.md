\# Landmark Annotator



A tool for selecting anatomical landmarks on 3D point clouds.



\## Requirements



\- Python 3

\- Open3D



\## Setup



From this directory, create a virtual environment:



```bash

py -m venv .venv



```bash

.venv\\Scripts\\activate



```bash

py -m pip install -r requirements.txt





\## Running

Enter virtual environment:

```bash
.venv\\\\Scripts\\\\activate


Then run:

```bash
py main.py
