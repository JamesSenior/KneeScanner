\# Landmark Annotator



A tool for selecting anatomical landmarks on 3D point clouds.



\## Requirements



\- Python 3

\- Open3D



\## Setup Windows



From this directory, create a virtual environment:



```bash

py -m venv .venv



```bash

.venv\\Scripts\\activate



```bash

py -m pip install -r requirements.txt





\## Running

Enter virtual environment:

```bash
.venv\\\\Scripts\\\\activate


Then run:

```bash
py main.py






\## Setup MAC



From this directory, create a virtual environment:



```bash

python3 -m venv .venv



```bash

source .venv/bin/activate



```bash

python3 -m pip install -r requirements.txt





\## Running

Enter virtual environment:

```bash
source .venv/bin/activate
